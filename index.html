자동 검출 스케줄러 동작 방식
  • 자동 검출 시간: 매일 장마감 후 오후 4시(16:00) 및 오후 7시(19:00) 정각 자동 스캔
  • 수집 대상: 금융감독원 DART OpenAPI 공정공시(잠정실적) 및 에프앤가이드(FnGuide)/연합인포맥스 증권사 3개월 컨센서스 평균치
  • 검출 공식:
    YoY(%) = ((당기실적 - 전년동기) / |전년동기|) × 100
    QoQ(%) = ((당기실적 - 전분기) / |전분기|) × 100
    컨센상회율(%) = ((당기실적 - 컨센서스) / |컨센서스|) × 100
현재 연동 상태 안내 (시뮬레이션 vs 실시간 DART 연동)

1) 웹 단독 화면(기본값): 금감원 DART 서버의 브라우저 보안(CORS) 정책과 개인 인증키 제한으로 인해 기본 상태에서는 내장 샘플 데이터 시뮬레이션으로 작동합니다.
2) 실제 DART 연동 방법: 아래에 금융감독원 OPENDART에서 발급받은 40자리 API 인증키를 입력하고 함께 드린 server.py를 실행(또는 CORS 프록시 사용)하면 오늘 실제로 올라온 DART 잠정실적 공시 목록과 원문 링크를 실시간으로 불러옵니다.

방법 A. Netlify Drop (10초) 가장 간편

코딩이나 서버 설정 없이 app.netlify.com/drop 페이지에 다운로드한 파일을 마우스로 끌어다 놓으면 즉시 https://...netlify.app 웹 주소가 발급됩니다.

방법 B. GitHub Pages / Vercel 평생 무료

함께 제공된 kr_earnings_web_deploy.zip 압축파일을 GitHub 저장소나 Vercel/Cloudflare Pages에 업로드하면 개인 도메인과 SSL이 자동 연결됩니다.

방법 C. DART 자동수집 서버 Python 백엔드

배포 패키지 내 server.py를 실행하면 매일 15:30 장마감 후 DART API를 자동 조회하는 자체 웹 서버(http://내서버IP:8000)가 구동됩니다.

현재 검출 조건 URL 파라미터(Hash) 공유 브라우저 LocalStorage 자동 저장 활성화됨
터미널 즉시 실행 명령어: python3 server.py --port 8000
